# modul — модуль агентской торговли

Локальный стек NinjaTrader / Sim101 / MNQ, панель защиты, API и перенос индикаторов TradingView.

Идёт исправление и проверка. Первая проверка исполнения обнаружила оставшийся стоп после рыночного выхода. До завершения исправления не считать модуль сертифицированным.

В репозитории только собственные исходники, обезличенные настройки и сборка с локально установленным NinjaTrader. Учётные данные, счета, рыночная база, журналы и библиотеки NinjaTrader не публикуются.
