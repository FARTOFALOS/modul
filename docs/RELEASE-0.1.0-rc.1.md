# v0.1.0-rc.1 — исходники модуля и проверенная F2

Исправлены потеря подтверждения позднего Flat и вводящий в заблуждение статус пустой позиции/потока котировок. Установлена F2 на исходном компьютере. 5258 risk/lifecycle tests; native build300 sources/1resource; экранные long/short, add/reduce, ручной take, BE с take, stop-filled cleanup и target-filled cleanup. Полная матрица: docs/VALIDATION.md.

Пакет source.zip содержит только собственные исходники, обезличенные настройки, документацию и сборочные scripts. Нужна установленная лицензированная NinjaTrader8/.NET4.8; пакет не является самостоятельным терминалом или публичной копией NinjaTrader.Custom.dll. Локальная compiled DLL, содержащая также сторонние исходники и ресурсы терминала, не включена.

Режим оператора SCREEN ONLY / Sim101. Live execution, произвольные partial fills/rejections/reversal и restart/disconnect с позицией не сертифицированы. Старый ограниченный Sim API остаётся в истории исходников, актуального разрешения его вызывать нет. IB-адаптер — требования, не реализация.
