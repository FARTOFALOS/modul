# Новый брокер или платформа (включая Interactive Brokers)

IB-адаптер в этой сборке НЕ реализован. Этот документ — граница будущего переноса.

Сохранить три независимых интерфейса: наблюдение рынка; состояние/исполнения счёта; управление собственными заявками. Наличие API не разрешает новые счета. Начинать с paper-счёта, точной идентификации контракта, timezone, tick size и point value; не переносить MNQ $2/пункт или комиссию OneUp на другой инструмент.

Адаптер должен явно описывать: account allowlist; контракты/rollover; порядок accepted/working/partial/filled/cancelled/rejected; owner/client-order ID и идемпотентность; восстановление после timeout и рестарта; сверку позиции с исполнениями; типы Limit/StopMarket/StopLimit и валидность цен; OCO (серверный или локальный); работу bracket после обрыва терминала; комиссию/валюту/проскальзывание; задержки котировок и entitlement.

Нельзя считать cancel завершённым по факту отправки или создавать защиту на закрытую позицию. Не принимать чужие заявки только по похожему Name. Не заменять наблюдение реальной позиции внутренним ожиданием. После реконнекта сначала reconciliation, затем отдельное разрешённое действие.

Приёмка: long/short; добавление; частичное закрытие; оба выхода stop/target с очисткой sibling; BE при существующем take; изменение/отмена pending-entry; дубли запросов и callbacks; выход до обновления позиции и обратный порядок; частичные fills; late reject; смена аккаунта/контракта; рестарт/обрыв без скрытых заявок. Отмечать NOT_TESTED отдельно от PASSED. Новая платформа не получает статус проверенной по тестам NinjaTrader.
