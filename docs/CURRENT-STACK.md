# Текущий стек — 06.11.2026

Это самостоятельный репозиторий модуля. Историческая полная спецификация скопирована в [STACK-ARCHIVE-1.0](STACK-ARCHIVE-1.0.md). Эта страница уточняет её устаревшие места.

## Слои

1. OneUp Evaluation предоставляет разрешённый счёт и учётные данные Rithmic. Они остаются в кабинете и NinjaTrader, не в git.
2. NinjaTrader Desktop 8.1.8.4 получает данные и исполняет заявки через нативное прямое Rithmic-соединение. Вариант `UsePluginData=false` работает без R|Trader Pro; plugin-mode — отдельная альтернатива, требующая работающий R|Trader Pro. Нельзя смешивать режимы и одновременные входы одного логина.
3. `MNQProtectionPanel` управляет защитой выбранного в Chart Trader MNQ-счёта. Стартовые общедоступные настройки — только Sim101, AllowLiveOrders=false, риск300, комиссия2 за круг. Уже настроенный оператором OneUp не является разрешением агенту отправлять туда заявки.
4. Экранный маршрут: явный Sim101 → Chart Trader / панель → заявки → подтверждение Accepted/Working → исполнения → фактическая позиция и остаточные заявки. После любой неопределённой реакции сначала перечитать экран, не повторять кнопку.
5. Существующий API v1 сохранён в исходниках для истории/проверяемости. Текущий операторский режим с 06.11 — торговые действия только через экран. API не вызывался после этого изменения. Его возможности ограничены Market1 на Sim101; он не реализует весь набор торговых команд.
6. TradingView Desktop отдаёт наблюдения локальному CDP 9222. Исправленный сборщик ищет готовые M5/M1 панели во всех chart-окнах и никогда не меняет символ, таймфрейм или активное окно. Отсутствие источника — ошибка с прежней датой кэша. Открытый TradingView без CDP больше не перезапускается.
7. DR Lab 23.5 — отдельный аналитический проект [dr-idr](https://github.com/FARTOFALOS/dr-idr). Локальные адреса 8735/23-5 или 8767/23-5, bind127.0.0.1. Семантика TP-1.4, закрытые M5; NQ/ES/YM читаются ежеминутно. Наличие процента не создаёт торговый сигнал. История2006–2025 остаётся локально, live не дописывается в историю.
8. Женский системный голос Zira сообщает новую DR-активацию по закрытой M5 для NQ/ES/YM. Одно событие один раз, старые активации на запуске молчат; очередь не отправляет ордера.
9. `TVPortSuite` и `TvPortCore` — отдельные индикаторы, без Account API. Это перенос Pine в C#, не автоматическая синхронизация исходников Pine. Проверка расчётов требует соответствующей версии скриптов и данных NQ/ES/YM.

## Восстановление рабочего места

Рабочее пространство сохранять, пока нужный график открыт. После штатного выхода подтверждать Save. При зелёном пустом workspace проверить: загружен ли Chart, не свёрнут/за пределами подключённых мониторов, какие NTWindows реально записаны в XML. Не лечить созданием бесконечных пустых workspace. Сделать резервную копию перед правкой XML. Пример профиля — config/sim101.json; он описательный и сам не меняет терминал. Аккаунты и координаты окон пользовательские, не переносить личный workspace вслепую.

## Сборка

Windows/.NET Framework4.8 и собственная установка NinjaTrader обязательны. `build.ps1` запускает тесты и воспроизводит полный локальный Custom.dll с сохранением сторонних исходников/ресурсов. Результат `.local/build` остаётся частным и не загружается на GitHub: DLL содержит не только наш код. `install.ps1` требует закрытый терминал, проверяет hashes исходников/входных файлов и сохраняет backup; не включает ATI, не меняет firewall, логины и подключения. Альтернативно NinjaScript Editor Compile и F5 на пустом Sim101-графике, с проверкой версии панели. Подтверждения доверия и авторизацию выполняет человек.

Отдельные исходники TV-port поставляются в src/tv-port; основной installer их автоматически не устанавливает. На новой установке импортировать их как индикаторы вместе с TvPortCore, скомпилировать и сверить конфигурацию. Настройки Pine пользователя, лицензированные скрипты и данные сюда не копировать.
